# 벅뚜벅뚜 (FootprintDiary) 👣

**두 발로 지난 자리만 남는 백지도.**

세상은 이미 네이버·카카오·구글이 다 그려 두었습니다. 그 위에 하나 더 그릴 이유는
없습니다. 이 앱의 지도는 아무것도 그려져 있지 않은 종이에서 시작하고, 당신이 걸어야만
한 점씩 채워집니다. 차나 지하철로 지난 길은 그려지지 않습니다.

앱은 화면 하나입니다 — 내가 걸어서 그린 지도 한 장.

## 무엇이 다른가

**1. 지표가 '걸은 거리'가 아니라 '그린 길이'입니다.**
같은 길을 백 번 걸어도 지도는 자라지 않습니다. 처음 지나는 길을 걸어야만 자랍니다.
그래서 이 숫자는 줄지 않고, 늘리려면 새 길로 가야 합니다. 이 값은 내 과거 기록 전체가
있어야 계산되므로 다른 앱이 흉내 낼 수 없고, '탐험'이라는 말의 정의 그 자체이기도 합니다.
(`WalkNovelty.swift`)

**2. 기록이 사라지지 않고 바랩니다.**
걸은 자리는 선이 아니라 10m 칸마다 찍는 점입니다. 자주 지난 칸일수록 짙어져서
생활 반경이 그대로 드러납니다. 빛깔이 묻는 것은 하나뿐입니다 — 오늘인가 아닌가.
오늘 걸은 자리는 주묵(붉은 먹), 지난 걸음은 남빛, 다시 밟지 않은 채 석 달이 지나면
잿빛으로 물러납니다. 사라지지 않고 **빛바랜 채로** 남는 것이 요점입니다.
(`WalkHeatmap.swift`)

**3. 가본 곳과 가볼 곳이 갈려 있습니다.**
지도를 길게 눌러 찍은 자리가 내가 걸어 본 땅 밖이면 '가볼 곳'으로 남습니다. 다녀온
자리는 속이 꽉 찬 붉은 도장, 가볼 곳은 점선 윤곽에 빈 속입니다. 그 자리 100m 안에
닿으면 물어서 '가본 곳'으로 굳습니다. 가름이 없으면 백지도가 내 발로 그린 것과 가고
싶은 곳의 뒤죽박죽이 되어, 지도가 하던 말을 잃습니다.
(`VisitedGround.swift`, `MapStamp.swift`)

## 화면과 기능

### 내 지도 (`AtlasScreen`)

앱의 본체. 종이 위에 걸음 점과 도장만 있습니다.

- **비춰보기** — 지도 아이콘을 **누르고 있는 동안에만** 배경 지도가 비칩니다. 켜 두는
  설정으로 두지 않은 까닭은, 한 번 켜 두면 그게 기본이 되어 그냥 '지도 위에 선 긋는 앱'이
  되기 때문입니다.
- **도장 찍기** — 왼쪽 아래 도장으로 지금 선 자리에, 지도를 길게 눌러 원하는 자리에.
  길게 누르면 근처의 내 길에 붙습니다(스냅). 찍은 뒤에도 끌어서 자리를 고칠 수 있습니다.
- **스탬프 212가지** — 갈래별로 묶여 있고, 걷는 중에 한 손으로 한 번 눌러 고르면 바로
  찍힙니다. 무엇을 새길지는 세 가지로 걸렀습니다 — 걸어야만 알 수 있는가, 한 손으로 한 번에
  찍을 수 있는가, 나중에 내가 실제로 다시 찾아볼 것인가. (`StampCatalog.swift`)
- **다시 다녀오기** — 근처에 서 있을 때만, 하루에 한 번만 셉니다. 손가락이 아니라
  발걸음을 세는 숫자여야 하기 때문입니다.

### 심볼 (스티커)

카메라로 그 자리의 간판을 한 장 찍으면 배경이 지워지고, 그때부터 지도에 '카페' 대신
그 가게 간판이 섭니다. 오려 낸 뒤 흰 테두리를 둘러 밝은 종이에서도 어두운 지도에서도
실루엣이 먹히지 않습니다. (`StickerMaker.swift`)

### 오늘의 발자취 (`DayTimelineScreen`)

지도 위 요약 판을 누르면 오늘 들른 곳이 시각 차례대로 섭니다. 자리 사이에는 얼마를
걸어서 왔는지가 적힙니다. 걸음이 짚어 낸 자리에 이미 도장이 있으면 "다녀오신 게
맞나요?"라고 묻고, 답하면 그 자리의 방문 횟수가 하나 늡니다. 아니라고 한 자리는
그날 다시 묻지 않습니다.

### 내가 찍은 곳 (`StampListScreen`)

같은 기록을 세로로 다시 세웁니다. 보는 길이 둘입니다 — **갈래별**은 '무엇을 모았나',
**오늘**은 '어디를 다녀왔나'에 답합니다. 아직 가보지 않은 곳은 갈래와 섞이지 않고 맨 위
한 묶음으로 섭니다.

오래 머물렀는데 아직 지도에 남기지 않은 자리는 "여기는 기록 안 해도 괜찮을까요?"라고
하루에 많아야 두 곳만 짚어 줍니다. (`StayPrompt.swift`)

### 개척 나침반 (`ExplorerCompassScreen`)

지금 선 자리를 한가운데 두고 둘레 1.5km를 여덟 방위로 갈라, 방위마다 얼마나 촘촘히
훑었는지(채움)와 얼마나 멀리 나가 봤는지(뻗음)를 잽니다. 여덟 뻗음을 이은 도형이
걸어서 넓힌 땅의 생김새이고, 바늘은 그 도형이 가장 얕게 팬 쪽을 가리킵니다. 판은
기기가 보는 쪽을 위로 두고 돕니다.

### 필름 (`FilmScreen`)

기간을 정해 내 지도가 그려지는 과정을 보고 영상으로 내보냅니다. 완성된 지도는 남에게는
'그림 한 장'이지만, 그려지는 과정은 어디서 시작해 어디까지 뻗어 나갔는지가 순서대로
드러나 이야기가 됩니다.

### 일지와 달력 (`DiaryScreen`, `WalkCalendarScreen`)

날짜별로 글과 사진을 남깁니다. 달력은 칸마다 숫자 대신 **그날 걸은 모양**을 그립니다 —
숫자는 아무 날에나 있지만 모양은 그날 걸은 사람만 가진 것입니다. 걷지 않은 날이 빈칸으로
남아 있어야 걸은 날이 무슨 뜻인지 보입니다.

### 위젯

- **홈 화면** — 오늘 그린 모양과 오늘 그은 길이. 앞세우는 숫자가 '걸은 거리'가 아니라
  '오늘 그은 길'인 것은 앱이 재는 것이 그것이기 때문입니다.
- **잠금화면** — 숫자 한 줄. 잠금화면은 색을 쓸 수 없어 오늘과 지난 걸음을 색으로 가를
  수 없으므로, 색으로 말하던 것을 억지로 흉내 내지 않고 숫자만 말합니다.

## 기록되는 것과 안 되는 것

| | |
|---|---|
| 걷기·뛰기로 판정된 구간 | ✅ 그려집니다 |
| 차량 속도로 움직인 구간 | ❌ 그려지지 않습니다 |
| 기록이 끊긴 사이(차를 탔거나 앱이 꺼져 있던) | ❌ 직선으로 잇지 않고 선을 끊습니다 |
| 정확도가 25m보다 나쁜 점 | 저장은 하되 **그리지 않습니다** |

마지막 줄이 이 앱의 규칙입니다 — **저장은 관대하게, 거르는 것은 그릴 때.**
오늘 안 남긴 점은 나중에 어떤 방법으로도 되살릴 수 없기 때문입니다. (`TrackSmoothing.swift`)

기록 촘촘함은 두 갈래로 고를 수 있습니다 (`TrackingMode.swift`).

- **정확한 기록 우선** — 앱이 꺼져 있어도 시스템이 깨워서 기록합니다
- **배터리 우선** — 앱을 열고 걷기 시작할 때만 기록합니다

## 데이터

**걸음·도장·일기·사진은 내 개인 아이클라우드(private)에 담깁니다.** 기기 안에만 두면
기기를 잃는 날 그 몇 해가 통째로 사라지기 때문입니다. 기기를 바꾸면 따라오고, 아이폰과
아이패드를 함께 쓰면 양쪽이 같은 지도를 봅니다. 아이클라우드에 붙지 못한 경우 설정
화면에 그렇게 적힙니다 — 조용히 안 되고 있는 것이 가장 나쁘기 때문입니다.
(`CloudSync.swift`)

**익명 통계는 아예 다른 그릇으로 갑니다.** 무엇을 보내지 *않는가*가 더 중요합니다.

- **좌표는 한 톨도 보내지 않습니다.** 얼마나 걸었는지만 보냅니다.
- 일기 글, 장소 이름, 사진은 보내지 않습니다. 몇 편을 썼는지만 셉니다.
- 누구인지는 보내지 않습니다. 설치할 때 뽑은 무작위 UUID 하나가 전부이고, 지웠다 다시
  깔면 남남이 됩니다.

(`FootprintUsage.swift`)

## 개발

### 요구 사항

- Xcode 16 이상
- iOS 17.0 이상 (SwiftUI + SwiftData + MapKit + WidgetKit)
- **실기기 권장** — 자동 위치 기록과 걷기/차량 판정은 시뮬레이터에서 제대로 재현되지 않습니다

### 실행

1. `FootprintDiary.xcodeproj`를 Xcode에서 엽니다.
2. **Signing & Capabilities**에서 본인의 Team을 선택합니다.
   아이클라우드 동기화까지 쓰려면 컨테이너 이름을 본인 것으로 바꿔야 합니다
   (`CloudSync.containerID`, 기본값 `iCloud.com.leeo.FootprintDiary`).
3. **Run (⌘R)**. 첫 실행에서 안내를 거치며 첫 도장 하나를 찍습니다.
4. 자동 기록을 쓰려면 나중에 뜨는 **"항상 허용"** 승급 요청도 허용해 주세요.

### 시뮬레이터에서 보기

시뮬레이터는 실제 이동이 없으므로 아래를 씁니다.

```sh
# 위치 권한을 미리 줘 두면 첫 실행에서 대화상자가 뜨지 않는다
xcrun simctl privacy booted grant location-always com.leeo.FootprintDiary
xcrun simctl location booted set 37.5665,126.9780

# 안내를 건너뛰고 지도부터 보고 싶을 때
xcrun simctl spawn booted defaults write com.leeo.FootprintDiary footprint.hasOnboarded -bool YES
```

경로를 쌓으려면 시뮬레이터 메뉴 **Features → Location → City Bicycle Ride / Freeway Drive**를
켜 두거나, **Custom Location…** 으로 좌표를 여러 번 옮깁니다.

### 배포

배포 규칙은 파일로 세워져 있습니다 (DeployBar가 읽습니다).

| 파일 | 역할 |
|---|---|
| `Version.xcconfig` | 버전·빌드번호가 사는 **단 한 곳**. 타겟(앱·위젯) 설정에 같은 이름을 다시 적으면 이 파일이 무시되므로 적지 말 것 |
| `deploy.env` | scheme·플랫폼·게이트 설정 |
| `scripts/predeploy.sh` | 배포 전 게이트. 버전 소스가 한 곳인지 보고 Release 빌드가 끝까지 서는지 확인합니다 |
| `release-notes/` | 버전별 릴리즈 노트 (비어 있으면 배포가 멈춥니다) |

> ⚠️ 이 앱에는 테스트 타겟이 없습니다. 게이트는 "고장 나지 않았다"가 아니라
> "컴파일은 된다"까지만 말해 줍니다.

## 코드 지도

파일마다 머리말에 **"왜 이렇게 했는가"**가 적혀 있습니다. 무엇을 하는지는 코드가
말해 주지만, 시도해 보고 접은 것과 그 까닭은 코드에 남지 않기 때문입니다.
손대기 전에 그 파일의 머리말을 먼저 읽어 주세요.

### 지도와 걸음

| 파일 | 역할 |
|---|---|
| `AtlasScreen.swift` | 앱의 본체 — 내가 걸어서 그린 지도 한 장 |
| `AtlasMap.swift` | 지도 본체 (종이 덮기·점 그리기·길게 눌러 찍기) |
| `AtlasStampAnnotation.swift` | 지도에 얹는 낙관(도장)의 생김새 |
| `WalkHeatmap.swift` | 걸은 자리를 칸으로 세어 점으로 찍는 셈과 오버레이 |
| `WalkNovelty.swift` | "오늘 걸은 길 중 처음 걷는 구간은 얼마인가" |
| `TrackSmoothing.swift` | 저장된 경로를 **그릴 때만** 다듬는다 |
| `FootprintPlace.swift` | 공간 격자(`SpatialGrid`), 장소 묶기, 걸은 길 자르기 |
| `VisitedGround.swift` | 좌표 하나를 두고 "거기 걸어 봤는가"에 답하는 격자 |
| `TerrainMap.swift` | 종이 아래 비치는 물·풀의 본 |
