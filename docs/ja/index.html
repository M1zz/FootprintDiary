벅뚜벅뚜とは？

世界はもう、ほかの地図が描き終えています。벅뚜벅뚜の地図は何も描かれていない紙から始まり、 あなたが歩いたときだけ一点ずつ埋まっていきます。 車や地下鉄で通った道は描かれません。

  • 歩いた分だけ育つ地図 — 通った場所が一点ずつ紙に刻まれます。 よく通る道ほど濃くなり、3か月歩かないと灰色に色あせます
  • 自分が描いた道 — 測るのは歩いた距離ではなく、はじめて歩く道の長さです。 同じ道を何度歩いても地図は育ちません
  • スタンプ — その場所に立って、212種類のスタンプから一つを押します。 カメラでお店の看板を撮ると、その看板が地図に立ちます
  • 行った場所と行きたい場所 — まだ行っていない場所は点線のスタンプとして残り、 そこに着くと行った場所として固まります
  • 開拓コンパス — 今いる場所から、どちらがまだ白いかを指し示します
  • フィルム — 自分の地図が描かれていく様子を動画で書き出せます
  • あなたのiCloudだけに — 歩みと日記、写真は、他人の目に触れない 個人のiCloudに保存されます。座標は開発者に一つも送信されません
